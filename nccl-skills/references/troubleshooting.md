# Troubleshooting

Use the pages below to narrow the problem down before changing NCCL settings.

* [GPU troubleshooting](troubleshooting/gpu_troubleshooting.md) covers GPU-to-GPU, GPU-to-NIC, ACS, topology, and multi-node NVLink issues.
* [Networking Troubleshooting](troubleshooting/networking_troubleshooting.md) covers interface selection, low-level fabric checks, latency and bandwidth tests, and InfiniBand or RoCE diagnostics.
* [Runtime and MPI issues](troubleshooting/runtime_and_mpi_issues.md) covers basic error handling, shared-memory and runtime problems, and MPI startup validation.
* [Performance and tuning](troubleshooting/performance_and_tuning.md) covers baseline performance triage and NCCL tuning knobs to try after system checks look healthy.
* [Logging](troubleshooting/logging.md) covers NCCL logging levels, subsystem filters, output files, and timestamps.
* [RAS](troubleshooting/ras.md) covers NCCL’s built-in RAS subsystem for diagnosing hangs and crashes.
